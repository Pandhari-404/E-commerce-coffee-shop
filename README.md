# E-commerce-coffee-shop ☕️

Welcome to my **E-Commerce Coffee Shop** project!  

This is a **fully functional online coffee shop website** where users can browse coffee products, add them to the cart, and enjoy a smooth shopping experience. The website is **responsive**, so it works perfectly on **desktop, tablet, and mobile devices**.  

I built this project as a part of my web development practice to improve **full-stack skills using Django and MySQL**.

---

## 🚀 Live Project

Check out the live project here:  
[E-Commerce Coffee Shop Live Demo](https://e-commerce-coffee-shop.onrender.com)  

---

## 🔧 Technologies Used

- **Frontend:** HTML, CSS, Bootstrap  
- **Backend:** Django (Python)  
- **Database:** MySQL  
- **Features:** Responsive design, Add to Cart (without login), Dynamic product listing  

---

## 🌟 Features

- Browse coffee products with images and details  
- Add items to the cart and increase quantity  
- Fully responsive design for all devices  
- Backend powered by Django with MySQL database  
- Easy to extend for more products and categories
